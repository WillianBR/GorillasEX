# GorillasEX v1.0.9 — Nome de login para o Jogador 1

- Inicialização do Jogador 1 procura `USERNAME`, `USER` e `LOGNAME`, nesta ordem.
- Se todas estiverem vazias, utiliza `PLAYER 1`.
- Remove caracteres de controle e limita a exibição inicial a 24 caracteres.
- Mantém a possibilidade de editar o nome pelo menu.
- Não modifica o nome do Jogador 2 nem os ajustes de lançamento.

**Compilação ainda não validada em QB64-PE.** Instale sobre a versão v1.0.8.
